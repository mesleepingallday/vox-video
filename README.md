# vox-video

Overflow storage for the Opus Editor project's shared folder (`opus-editor/`).
Large finished outputs, superseded renders and raw footage are moved here when
the project folder runs low on space. See `opus-editor/playbook/OVERFLOW.md` in
the project for the recipe.

The old Tencent explainer draft that used to live here is still in the git
history (commit 38fc7db).
